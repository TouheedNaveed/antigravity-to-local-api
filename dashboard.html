Continue (~/.continue/config.yaml):

        
Open WebUI: Admin Settings → Connections → OpenAI API → add a connection with the URL and your key. If Open WebUI runs in Docker, 127.0.0.1 is the container itself: use http://host.docker.internal:8790/v1 and start this server with HOST=0.0.0.0 (then keep the API key on and firewall the port), or run the container with --network=host.

        
Cursor: Settings → Models → OpenAI API Key + Override OpenAI Base URL. Be aware that Cursor sends those requests from its own servers, so a 127.0.0.1 address is usually not reachable that way; it would need a public tunnel URL (not recommended without a strong key). Continue, Open WebUI and your own code work locally.
